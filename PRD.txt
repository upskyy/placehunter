🌍 여행 장소 자동 추천 웹 서비스 PRD
📌 개요

반복되는 해외여행 검색 피로도를 줄이기 위해, 사용자가 도시명과 키워드(예: 맛집, 카페, 식당 등)만 입력하면 해당 도시의 구글 평점 기준으로 필터링된 장소 목록을 자동으로 보여주고, 나아가 이들 장소를 기반으로 최적의 **가벼운 여행 루트(동선)**를 제안하는 웹 서비스를 구축한다.

기술 스택은 자유롭게 구현 가능하며, 제한 없음.

🎯 제품 목표

도시명 + 키워드 기반 장소 검색 자동화

구글 리뷰 평점 기반 필터링 제공 (예: 4.3점 이상)

선택된 장소 간의 효율적인 동선 추천 (걷기/대중교통 중심)

향후 사용자의 취향/히스토리를 기반으로 개인화된 장소 추천으로 확장 가능

🧑‍💻 사용자 시나리오
🧳 사용 예시 1: 여행 장소 필터링

사용자가 도시명을 입력 (예: Rome)

키워드 입력 (예: "카페")

평점 기준 설정 (기본 4.3점 이상)

결과: 평점 조건을 만족하는 장소 목록 + 기본 정보 (이름, 평점, 주소, 영업시간 등)

🧭 사용 예시 2: 동선 생성

사용자가 최대 10개 장소를 선택

“동선 생성하기” 클릭

도보 혹은 대중교통 기반으로 시간 최적화된 방문 순서를 추천

💡 핵심 기능
1. 장소 필터링 기능

 도시명 및 키워드 입력 UI

 구글 플레이스 API 또는 기타 크롤러 기반 장소 검색

 평점, 리뷰 수, 영업시간 등의 조건으로 필터링

 장소 썸네일/지도 보기 옵션 포함

2. 여행 루트 생성기 (경량)

 선택된 장소들의 위치 기반 최단 동선 알고리즘 적용

 루트 시각화 (구글맵 연동 또는 자체 지도)

 이동 예상 시간 및 소요 시간 출력

 옵션: 시작 시간/예상 방문 시간 등 입력받아 커스터마이즈

3. UI 및 UX

 도시/키워드/평점 입력 폼

 결과 목록 카드형 UI

 장소 선택 및 루트 확인 페이지

 (선택) 마이리스트 저장 및 공유 기능

📂 데이터 소스 및 외부 연동
기능	사용 API	비고
장소 검색	Google Places API	키워드/도시 기반
평점/리뷰	Google Maps Details API	
지도 & 동선	Google Directions API 또는 OSRM	도보/대중교통 기준
생성 & 임베딩 OpenAI API
대체 옵션	웹 크롤링	비용 절감 목적시 고려 가능
🔒 비기능 요구사항

빠른 응답성 (로딩 < 2s)

모바일 및 데스크톱 모두 대응 (반응형 디자인)

멀티 도시/멀티 키워드 확장 고려한 설계

사용자 데이터 저장은 선택 사항으로 처리 (개인화 추천 시 활용)

📦 개발 환경 제안

기술 스택은 자유롭게 선택 가능하나, 다음 제약을 고려한 예시는 다음과 같음:

웹 프론트엔드: TypeScript 기반 SPA

백엔드 언어: Python

환경 관리: Docker / Docker Compose

API 연동: Google Maps Platform

배포: 클라우드 or VPS (예: Render, Railway, Vercel, EC2 등 자유)

📈 향후 확장 방향 (v2, v3)

GPT 기반 추천 키워드 자동 완성

사용자 여정 기반 자동 일정 생성

개인화 여행 성향 분석 및 취향 기반 추천

사용자 리뷰 기반 평점 대체 지표 도입
